# follow-the-money

Tracks gifts, hospitality, and financial interests disclosed by Australian politicians.

## Scope

- Members and Senators of the Australian Parliament
- Sources: Register of Members' Interests, Register of Senators' Interests, ministerial disclosures
- Captures: gifts received, sponsored travel, shareholdings, real estate, directorships, trusts, liabilities

## Status

Early-stage. No data ingested yet.
